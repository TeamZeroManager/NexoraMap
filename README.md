# NexoraMap

NexoraMap is a performance-first Minecraft map mod derived from the MIT-licensed Diorama project.

## Target
- Minecraft 1.20.1
- Fabric
- Java 17

## Priorities
1. Maximize performance and minimize CPU, GPU, memory, and background workload.
2. Allow visual-quality reductions when they produce meaningful performance gains.
3. Preserve core map usability while offering scalable quality/performance presets.
4. Give NexoraMap its own visual identity and interface.

## Planned optimization direction
- Adaptive scheduling and prioritization of nearby/relevant map regions.
- Configurable map detail, render distance, effects, and update rates.
- Efficient tile baking, caching, and memory management.
- Low-, balanced-, and high-performance profiles, with conservative defaults.
- A redesigned interface and visual assets distinct from Diorama.

## Development status
Repository setup is in progress. These are goals, not implemented or benchmarked features.
