# NexoraMap

NexoraMap is a performance-focused Minecraft map mod.

## Target
- Minecraft 1.20.1
- Fabric
- Java 17

## Goals
- Reduce CPU, GPU, memory, and background workload.
- Preserve the map's visual quality.
- Prioritize nearby and relevant map regions.
- Add an original adaptive performance system.

## Development status
Project setup in progress. No optimization or feature implementation is claimed yet.
